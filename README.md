# Products CRUD (prompt version)

A simple CRUD exercise. The products live in two arrays (names and prices) and the user types everything with `prompt()`.

## What it does

- **Read**: shows all the products in a table
- **Add**: asks for a name and a price
- **Update**: asks for the product number, then the new name and price
- **Delete**: asks for the product number

It checks the input, so a wrong number, an empty name or a price that is not a number is rejected.

## Built with

HTML, CSS and JavaScript (arrays, loops, functions, DOM).

## How to run

Open `index.html` in your browser.
